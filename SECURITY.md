# Security policy

## Reporting a vulnerability

Please do not report security problems in a public issue.

Report them privately instead: email <enrove@studioen.us>, or open the **Security** tab
of this repository and choose **Report a vulnerability**. Include the plugin version, the
steps to reproduce the problem, and what an attacker could do with it.

You should get a reply within a week. Once a fix is released, the report is credited in
`CHANGELOG.md` unless you would rather it were not.

## Supported versions

Only the latest release receives security fixes. Enrove Folios is in beta, so please
update before reporting.
